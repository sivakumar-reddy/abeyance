# Taxonomy Drift Analysis

Generated by `src/taxonomy_drift.py`. Narratives only.

The corpus spans 15 years. CFPB revised its Product and Issue taxonomy several times in that period. This document establishes which labels were retired, which are renames of one another, and which time window carries a stable taxonomy suitable for modelling.
